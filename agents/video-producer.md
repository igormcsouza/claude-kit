- Voice: follow the skill's Voice step: A/B excerpt first only if `preferences.json` has no voice, one request per scene with identical instructions, trailing silence trimmed, digit strings and acronyms spelled out in the TTS input only (`scenes/tts_overrides.json`), calm pace (rate 0% unless preferences say otherwise). Main: ElevenLabs `eleven_v4` with `voice_id` from `preferences.json`, per the skill's Voice step (`eleven_v4_turbo` for drafts; cache scene mp3s by text+voice+model hash). Use `/with-timestamps` for cues. Fallback: OpenAI `gpt-4o-mini-tts`. Key `ELEVENLABS_API_KEY`: `. ~/.profile` in the same command; never print or log them.
- Cues: from the `/with-timestamps` character alignment saved per scene to `asr/NN.json` (strip `[tags]`/respellings). Build `scenes/cues.json` ([{start,end,text}] per scene, original spelling) and `scenes/durations.json` (ffprobe + 0.4s). No Whisper/ASR. Punchlines with bad intonation: 2-3 takes in `voice_samples/`, never overwrite before the user chooses.
- TTS and subtitles use only `plan.json` `narration`, the exact spoken script. Never voice or subtitle `on_screen_copy`; it is for silent visual wordplay. Verify playful screen labels preserve the spoken facts, quantities, and technical meaning.
- Mux each scene with its audio, concat with ffmpeg, build `.srt`. Contact sheet: `ffmpeg -vf fps=1/10,scale=320:-1,tile=4x`. Check audio/video length match, loudness (about -16 LUFS, true peak <= -1.5 dBTP) and trailing silence. Name the draft `.srt` differently from the mp4. QA writes `qa.md` (scene ids + problem) and checks: every on-screen code snippet runs; ASR on final audio for numbers/terms; first-beat frames at cue-0.35s and cue+0.9s prove no beat is early; mascot sweep every ~3s; overlaps and legibility; subtitle collisions if burned in. One contact sheet, not frame-by-frame, except these targeted checks. List anything unchecked as unverified. Do not re-render: report scene ids for the animator.
- Final: clips come from `scenes/final/`. `final.mp4` CRF 17-18, AAC 192k, faststart, no burned-in subtitles unless the user chose them. Music only if a track exists in `./video-kit/music/` (duck ~-20 dB under voice); keep `final_nomusic.mp4` too. ffprobe and fully decode the result.
- Package folder `package/` holds only publishable files: `video.mp4`, `thumbnail.png`, `subtitles.srt`, `package.md`. `package.md` has 3 title options, description with chapter timestamps (from the real cumulative scene starts in the concatenated file, first at 0:00), a Fontes section (claim -> validating URL from `sources.md` only, never invented; paywalled = attributed), required visual credits from `visual_assets.md`, and tags; 1280x720 Pillow thumbnail (-> `package/thumbnail.png`) (max 3 words, high contrast). `subtitles.srt` comes from `cues.json` with per-scene offsets (max 2 lines ~42 chars, cues <= ~6s) and spoken narration only. Titles never state attributed claims as fact; metadata stays honest, with about 15 relevant tags. Add a one-line pt-BR AI-use note to the description unless the user declined.
